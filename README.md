# 放課後ソーダ / 放学后的汽水

一个可以双击直接玩的番剧化视觉小说。日常向，单女主，青梅竹马。
四章正文 + 三条结局，约 20 分钟。全程带日语配音（VOICEVOX）与情绪 BGM。

## 怎么玩

1. 解压整个文件夹（不要只解压 index.html）。
2. 双击 `index.html`，用 Chrome / Edge / Firefox 打开。
3. 不用装任何东西，不用联网，不需要开服务器。

## 操作

| 操作 | 说明 |
| --- | --- |
| 点击画面 / `Space` / `Enter` | 推进对话 |
| 数字键 `1` `2` `3` | 选择选项 |
| `Esc` | 关闭记录 / 设置面板 |
| 记录 | 回看已读文本 |
| 设置 | 音乐、语音、文字速度、结局收集 |

进度会自动保存在浏览器里（`localStorage`）。换浏览器、清理浏览器数据、用无痕窗口都会丢存档。

## 手机 / 平板

把整个文件夹放到手机里，用支持本地文件的浏览器打开 `index.html` 即可。
iOS 的「文件」App 预览不能运行脚本，请用 Safari 打开网页版或改用电脑玩。

## 制作与署名

- **音声**：VOICEVOX:四国めたん（小春）。VOICEVOX 的使用条款要求署名，发布时请保留这一行。
- **BGM**：本包内为程序合成的占位音轨，仅用于开发试听。正式发布请替换为 DOVA-SYNDROME 等免费可商用曲库，并在设置页列出曲名与作者。
- **图像**：AI 生成素材，已做去水印与透明化处理。
- **剧本 / 角色 / 地名**：均为虚构，与真实人物、地点无关。

## 文件结构

```
index.html          入口
css/                舞台、版式、主题
js/
  engine.js         步进引擎
  bgm.js            BGM 管理器（纯 audio 元素，无 WebAudio 跨域问题）
  voice.js          配音播放器
  audio.js          环境音（WebAudio 实时合成）
  data.js           角色 / 结局 / 默认设置
  story_01~04.js    剧本
assets/
  bg/  cg/  char/  背景、CG、透明立绘
  bgm/              8 首情绪曲目
  voice/            29 句配音 + manifest.js
```

配音文件名规则是 `场景id_步进下标.wav`。删掉某个 wav 时请同时从 `assets/voice/manifest.js` 里删掉对应 id，播放器才不会去找不存在的文件。

## 想改台词

剧本在 `js/story_0*.js`，每句是一个对象：

```js
{ t: 'line', c: 'koharu', x: '中文台词', jp: '日语台词', vo: true }
```

`vo: true` 表示这句要配音，`jp` 是送进 VOICEVOX 的日文。改完重新跑一次抽取与合成脚本即可。
